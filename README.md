# Smart Transfer and Logistics Planning System — Version 1 (Hosting Ready)

This is the hosting-ready version of the student project prototype.

## Stack
- Python
- Flask
- SQLite (demo database)
- HTML/CSS
- Gunicorn for production-style serving

## Included project modules
1. Vehicle Allocation
2. Delivery Scheduling
3. Driver Management
4. Vehicle Maintenance Tracking
5. Failed-Delivery Management & Rescheduling

## Quick local test

### Windows
```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

### Linux/macOS
```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python app.py
```

Then open:
`http://127.0.0.1:5000`

## Deploy to Render

1. Create a GitHub repository.
2. Upload all files in this folder to the repository.
3. In Render, create a new Web Service and connect the GitHub repository.
4. Render can use the included `render.yaml` configuration.
5. The start command is:
   `gunicorn app:app`
6. A `SECRET_KEY` environment variable is generated by the Render configuration.

## Important database note

Version 1 still uses SQLite because it is simple and suitable for a school demonstration.

For a reliable public deployment where data must survive redeploys/restarts, move the database to PostgreSQL before treating the system as production software. SQLite files on many cloud hosting platforms are not guaranteed to persist across redeploys.

## Academic/demo note

This version is intended for a final-year project demonstration and is not a production logistics platform. Authentication, payment processing, live GPS tracking, SMS/email notifications, and PostgreSQL persistence are not included in Version 1.
